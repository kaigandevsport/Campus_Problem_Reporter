About This Project

In a college campus there are many small problems such as broken benches, water leakage, dirty washrooms or lights not working. Students often do not know where to report them. This project gives a simple form where any student can write the problem and its location so that it can be fixed.

Easy to use

Fill one simple form to report a problem.

Clear categories

Choose from water, electricity, classroom, hostel and more.

Track status

See which problems are pending or solved.
